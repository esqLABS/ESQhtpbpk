# Get original values of the parameters from simulation used in batches

Get original values of the parameters from simulation used in batches

## Usage

``` r
.getDefaultParameters(simulation, parameterStartValues)
```

## Arguments

- simulation:

  A Simulation object, to get the parameters from.

- parameterStartValues:

  List of parameter start values, with names being parameter paths

## Value

a list of the default parameter values for each simulationBatch (in
internal units)
