# Create generic pkml from a list of study

Create generic pkmls from a list of study

## Usage

``` r
createGenericPKMLs(studyList, outputFolder, overwrite = FALSE)
```

## Arguments

- studyList:

  list of Study for which to create generic pkmls

- outputFolder:

  Folder were to write the generic pkmls

- overwrite:

  If TRUE, overwrite existing files

## Value

The update studyList with model to use, and adjusted paths.
